# 🛍️ Retail Sales & Campaign Analytics

## 📌 Project Overview

**Retail Sales & Campaign Analytics** is a data analytics project focused on understanding retail sales performance, customer behavior, household characteristics, and campaign effectiveness.

The project follows a complete data analytics workflow, starting with data research and acquisition, followed by Python-based data preparation, SQL analysis, and Power BI dashboard development. The final goal is to transform raw retail data into clear KPIs, trends, customer segments, and actionable business insights.

## 🎯 Project Objectives

- Analyze weekly retail sales performance.
- Understand sales patterns across departments.
- Analyze customer behavior and household characteristics.
- Segment customers using **RFM Analysis**.
- Evaluate campaign targeting and coupon redemption.
- Identify data quality and consistency issues.
- Develop business-focused KPIs and visualizations.
- Present meaningful insights that can support better business decisions.

## 📂 Dataset

The project uses a retail dataset containing multiple related tables:

| Dataset | Description |
|---|---|
| `campaign_desc` | Campaign descriptions and campaign periods |
| `campaign_table` | Campaign-related household and product information |
| `causal_data` | Promotional and causal product information |
| `coupon` | Coupon information |
| `coupon_redempt` | Coupon redemption records |
| `hh_demographic` | Household demographic information |
| `product` | Product information and categories |
| `transaction_data` | Retail transaction and sales data |

## 🔍 Project Scope

The analysis covers:

1. **Sales Performance** — Weekly sales, transactions, baskets, and units sold.
2. **Department Analysis** — Comparing sales performance across departments.
3. **Customer Analysis** — Understanding customer and household characteristics.
4. **RFM Segmentation** — Classifying customers based on recency, frequency, and monetary value.
5. **Campaign Analysis** — Evaluating targeted households and coupon redemption.
6. **Data Quality** — Checking missing values, inconsistencies, and invalid records.
7. **Business Insights** — Turning analytical results into useful findings.

## 📊 Key Performance Indicators (KPIs)

- **Total Sales**
- **Number of Transactions / Baskets**
- **Customer Count**
- **Units Sold**
- **Sales by Department**
- **Sales by Income Group**
- **Customer RFM Segments**
- **Campaign Redemption Rate**
- **Weekly Sales Trends**
