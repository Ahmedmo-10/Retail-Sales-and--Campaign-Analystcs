# Retail Sales & Campaign Analytics

## Project Idea

A data analytics project focused on retail sales, customer behavior, campaigns, and business insights. The project follows a complete data workflow using Python, SQL, and Power BI, starting from data acquisition and preparation and ending with interactive dashboards and business insights.

## Work Plan

**Data Research & Acquisition → Python → SQL → Power BI → Final Presentation**

### 1. Data Research & Acquisition
Research, identify, and collect the dataset required for the project.

### 2. Python
Explore, clean, prepare, and process the raw data.

### 3. SQL
Prepare the analytical database, establish table relationships, perform SQL queries, and analyze the data.

### 4. Power BI
Transform the analyzed data into an interactive dashboard containing KPIs, visualizations, trends, and business insights.

### 5. Final Presentation
Present the project workflow, analysis, dashboards, and key findings.
